Editing Popup Overlay Panel sections

QuickInspect shows what you need to know about any element without opening DevTools: selectors, the box model, computed styles, accessibility, attributes, events and the source file it came from.

  1. Hold Alt / Option and hover any element to inspect it, release to put the page back. Pick a different key under Hold key on the main screen.
  2. Click while holding to pin the panel, then drag its header to move it. Use ↑ ↓ for the parent or child.
  3. Press S X L H T to copy the selector, XPath, Playwright locator, HTML or text.
  4. In a pinned panel, click any value to edit styles, box, attributes or text. Enter applies, Esc cancels and reset undoes it all. Edits stay in the page until you reload.
  5. On a Vite or Next.js dev server, press O to open the element's source in your editor.
